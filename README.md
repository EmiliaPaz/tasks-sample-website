# Website

A small sample site. The README itself is tracked as WEB-5, and the login
screen (WEB-2) is still in review.

Run the tests:

```sh
npm test   # the board columns come from WEB-3
```

## Not task keys

The page is served as UTF-8, assets are pinned by SHA-256 hash, and dates use
ISO-8601. WEB-99 does not exist, and lowercase web-2 is not a key either.
